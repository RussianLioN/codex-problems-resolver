# Устранение усечения описаний навыков Codex

## Назначение

Инструкция устраняет предупреждение Codex CLI об усечённых описаниях навыков, не удаляя плагины и не меняя способ обычного запуска `codex`.

## Предусловия

- Установлен Codex CLI с командой `codex`.
- В репозитории `codex-problems-resolver` доступен скрипт `scripts/validate_skills_context.py`.
- Владелец утвердил отключение только `chronicle` и `batch-task-authoring`.

## Диагностика до изменения

```sh
codex debug prompt-input | python3 scripts/validate_skills_context.py
```

Код `1` означает усечение; вывод содержит только имя навыка и число потерянных символов. Не сохраняйте полный JSON вывода: он может содержать контекст текущей сессии.

## Применение

1. Запустить обычный `codex` без `--profile`.
2. Ввести `/skills`.
3. Убедиться, что в списке доступны оба навыка: `chronicle` и `batch-task-authoring`.
4. Только если доступны оба, переключить каждый в состояние «выключен».
5. Выйти из списка и завершить текущую сессию. Новая сессия получит обновлённый каталог.

Если хотя бы одного навыка в `/skills` нет, не отключайте второй навык и не редактируйте `~/.codex/config.toml` вручную. Зафиксируйте версию Codex, результат диагностики и отсутствие навыка, затем передайте применение автоматизации, которая использует штатный app-server метод `skills/config/write` с точным путём `SKILL.md`. Не удаляйте плагины и не подавляйте предупреждение. Отключение навыка отличается от удаления его плагина.

## Проверка после применения

```sh
codex debug prompt-input | python3 scripts/validate_skills_context.py
codex plugin list --json
```

Ожидаемые признаки:

- первая команда завершается кодом `0` и сообщает, что описания не усечены;
- в модельном вводе 66 навыков;
- в JSON списка плагинов нет удалённых плагинов.

Затем вручную проверить три интерфейсных сценария:

1. Запустить новую сессию `codex` — предупреждение не появляется.
2. Выполнить `codex resume` и выбрать сохранённую сессию — предупреждение не появляется.
3. В активной сессии выполнить `/compact` — предупреждение не появляется.

## Откат

1. Запустить `codex` и открыть `/skills`.
2. Включить `chronicle` и `batch-task-authoring`.
3. Завершить сессию и открыть новую.
4. Повторить команду диагностики из раздела «Диагностика до изменения».

После отката предупреждение может вернуться: это ожидаемый признак возврата к прежнему размеру каталога.
