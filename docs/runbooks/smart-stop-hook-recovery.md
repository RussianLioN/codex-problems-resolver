# Диагностика и восстановление Stop-хука

## Назначение

Инструкция применяется, когда Codex сообщает `Stop hook timed out`, выводит некорректный JSON события `Stop` либо после завершения остаются дочерние процессы обработчика.

## Предусловия

- Работать из чистой отслеживаемой рабочей копии `codex-settings`.
- Использовать реальный путь `CODEX_HOME`; не подменять его временным каталогом при проверке живой установки.
- Не редактировать файлы внутри `<USER_HOME>/.codex/plugins/cache` и неизменяемых активаций.
- Не завершать процессы Codex или ChatGPT общими командами `killall` и `pkill`.

## Безопасная диагностика

Проверить состояние установленной активации:

```sh
python3 scripts/install_adaptive_subagents.py --inspect --json
python3 scripts/install_adaptive_subagents.py --doctor --json
```

Ожидаемый результат: активная активация имеет состояние `FULL_READY`, журналы незавершённых операций отсутствуют, а диагностика не сообщает расхождение дерева.

Проверить исходники и целевые регрессии:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.smart_subagents.test_plugin_integration tests.smart_subagents.test_integration_runtime_v2 tests.smart_subagents.test_resume_session_v2
git diff --check
```

Ожидаемый результат: проверки завершаются кодом 0. Искусственно медленный обработчик возвращает один JSON `SMART_HOOK_DEFERRED` раньше внешнего срока; его дочерняя группа не остаётся живой.

## Предварительная установка

```sh
python3 scripts/install_adaptive_subagents.py --preview --json
```

Не применять изменение, если результат содержит `PYTHON_ENTRYPOINT_INVALID`, незавершённый журнал, неподтверждённую активацию или ошибку владения. Сначала исправить источник либо восстановить установочный журнал штатным режимом `--recover --preview`.

## Применение

После успешных проверок и слияния исходников:

```sh
python3 scripts/install_adaptive_subagents.py --apply --json
python3 scripts/install_adaptive_subagents.py --apply --json
python3 scripts/install_adaptive_subagents.py --doctor --json
```

Первый запуск создаёт новую неизменяемую активацию и сохраняет предыдущую для отката. Второй запуск доказывает идемпотентность и не должен создавать новое изменение. Диагностика должна вернуть готовое состояние.

Новые сеансы Codex должны использовать новую активацию. Уже открытые сеансы не требуется аварийно завершать.

## Признаки ошибки

- `PYTHON_ENTRYPOINT_INVALID` — материализатор не распознал строго разрешённую точку входа Python.
- `SMART_HOOK_DEFERRED` — срок внутри Stop исчерпан безопасно; обработку следует продолжить на следующем ходе.
- внешний `hook timed out` — родительский надзор не успел выдать ответ; установка либо исходники не соответствуют исправленному контракту.
- незавершённый установочный журнал — сначала выполнить штатное восстановление, не повторять применение вслепую.

## Восстановление и откат

Сначала получить план без изменения состояния:

```sh
python3 scripts/install_adaptive_subagents.py --rollback --preview --json
```

После проверки точной предыдущей активации применить откат и сверить результат:

```sh
python3 scripts/install_adaptive_subagents.py --rollback --apply --json
python3 scripts/install_adaptive_subagents.py --inspect --json
python3 scripts/install_adaptive_subagents.py --doctor --json
```

Откат не должен завершать общие процессы Codex или ChatGPT. Если автоматическое восстановление отказывается работать, сохранить обезличенный вывод, открыть отдельный инцидент и не править квитанции или манифесты вручную.

## Редактура доказательств

Перед публикацией заменить домашний путь на `<USER_HOME>`, частные узлы на `<PRIVATE_HOST>`, удалить токены, cookie, заголовки авторизации, идентификаторы сессий и полный текст пользовательских запросов.
