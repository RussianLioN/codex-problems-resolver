# Устранение малого предела открытых файлов в Codex

## Назначение

Инструкция настраивает обычный интерактивный запуск `codex` с неограниченным пределом открытых файлов оболочки и сохраняет существующую обёртку с умным запуском.

## Предусловия

- Используется оболочка `zsh`.
- Существует файл `$HOME/.codex/codex-autonomous-aliases.zsh`.
- Существует исполняемый файл `$HOME/.local/bin/codex-highfd`.
- Изменяется только `$HOME/.zshrc`.

## Применение

1. Создайте резервную копию `$HOME/.zshrc`:

   ```zsh
   (
     backup_path="$HOME/.zshrc.codex-highfd-backup-$(date +%Y%m%d-%H%M%S)"
     [ ! -e "$backup_path" ] || { print -u2 "Резервная копия уже существует: $backup_path"; exit 1; }
     cp -p "$HOME/.zshrc" "$backup_path"
   )
   ```

2. Откройте `$HOME/.zshrc`.
3. Найдите точную существующую строку подключения:

   ```zsh
   test -e "${HOME}/.codex/codex-autonomous-aliases.zsh" && source "${HOME}/.codex/codex-autonomous-aliases.zsh"
   ```

4. Сразу после неё добавьте ровно одну новую строку:

   ```zsh
   alias codex='ulimit -n unlimited; CODEX_SMART_ENABLED=1 "${HOME}/.local/bin/codex-highfd"'
   ```

5. Закройте текущий терминал и откройте новый. Уже запущенные процессы не меняются.

Не меняйте `launchctl`, перехватчики, `$HOME/.codex/config.toml`, квитанцию установки или активные процессы.

## Проверка

В новом терминале выполните:

```sh
zsh -ic 'ulimit -n 256; eval "alias codex; codex --self-test"'
```

Ожидаемый результат: `soft_limit=unlimited` и `hard_limit=unlimited`. Команда предназначена для самопроверки и не запускает обычную рабочую сессию Codex.

Признак ошибки — отсутствие alias или сохранение значения `256`; проверьте положение строки после подключения файла и повторно откройте терминал.

## Откат

Удалите из `$HOME/.zshrc` только добавленную строку alias и откройте новый терминал.

## Редакция данных

Не сохраняйте в журнале полные пути пользователя, секреты, токены, cookie или необезличенные журналы. Используйте `$HOME`, `<USER_HOME>`, `<REDACTED_TOKEN>` и `<PRIVATE_HOST>`.
