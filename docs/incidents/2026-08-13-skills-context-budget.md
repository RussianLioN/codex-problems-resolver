# Инцидент 2026-08-13: усечение описаний навыков Codex

## Краткий симптом

При создании новой сессии Codex CLI, возобновлении сохранённой сессии и после `/compact` выводится предупреждение о том, что описания навыков были сокращены для соблюдения бюджета контекста.

## Окружение и воспроизведение

- Codex CLI 0.147.0 на macOS.
- До исправления включено 68 навыков.
- Для воспроизведения запустить обычный `codex`, возобновить сессию через `codex resume` или в активной сессии выполнить `/compact`.

## Обезличенные доказательства

Команда ниже показала 16 409 символов полных описаний при доступных 15 733: усечено 676 символов.

```sh
codex debug prompt-input | python3 scripts/validate_skills_context.py
```

Доступный журнал Codex был проверен на явные чтения `SKILL.md`. Навыки `chronicle` и `batch-task-authoring` не имели таких чтений. Полные описания этих двух навыков занимают 544 и 239 символов соответственно, всего 783 символа.

## Первопричина

Codex формирует список доступных навыков в модельном вводе с ограниченным суммарным бюджетом описаний. Этот список формируется при старте, возобновлении и сжатии сессии, поэтому предупреждение повторяется во всех трёх сценариях. Это не ошибка самого механизма сжатия истории.

## Предусмотренное исправление

Целевое исправление — отключить только `chronicle` и `batch-task-authoring`. Плагины остаются установленными; шаблоны, генерация изображений, Excel, презентации и установщик навыков не изменяются.

Новая команда `scripts/validate_skills_context.py` читает JSON `codex debug prompt-input`, сопоставляет только имена и длины описаний с локальными метаданными `SKILL.md` и возвращает:

- `0`, если усечения нет;
- `1`, если найдены сокращённые описания;
- `2`, если ввод или путь к навыку некорректен.

## Ограничение текущей версии

В Codex CLI 0.147.0 `/skills` показал `chronicle`, но не показал `batch-task-authoring`, даже при поиске точного имени. Для проверки интерфейса `chronicle` был отключён и сразу включён обратно.

Сгенерированная самим Codex схема app-server подтвердила штатный метод `skills/config/write` с выбором по имени или абсолютному пути `SKILL.md`. Через этот метод отключены точные пути обоих навыков; ручное изменение `config.toml` не применялось. После применения `codex debug prompt-input` показал 66 навыков без усечения, а `codex plugin list --json` подтвердил 10 установленных и включённых плагинов.

## Проверки

После отключения двух навыков ожидается 66 навыков, отсутствие усечения в диагностике и отсутствие предупреждения в новой, возобновлённой и сжатой сессиях.

## Риски и откат

В новых сессиях Codex не сможет автоматически выбрать два отключённых навыка. `chronicle` перестанет быть доступным агенту, но запись экрана не останавливается этим действием. Откат выполняется через `/skills`: включить оба навыка и повторить диагностику.
