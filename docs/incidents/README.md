# Формат доказательств инцидентов

Этот каталог хранит разборы инцидентов Codex, когда доказательства должны быть частью отслеживаемой истории Git.

Для политики репозитория путь `classic_evidence.tracked_reference` должен указывать на обычный отслеживаемый Markdown-файл внутри `docs/incidents/`. Ссылки на временные каталоги, неотслеживаемые файлы, игнорируемые файлы и символические ссылки недопустимы.
